# U-NEXT実機検証

U-NEXTの実画面での動作確認は、ログイン済みのWindows PCで実施する必要があります。このリポジトリの再現用テストを通過したことと、U-NEXTへの対応確認は別の記録です。

## 確認する順序

1. バックエンドの接続を確認し、直接入力した短いテキストが再生される。
2. 参照音声を登録・選択し、再起動後も同じ音声が選べる。
3. 読書画面の本文を範囲指定して、横書き・縦書きのOCRが適切な順序になる。
4. 自動読書を開始し、クリック、キーボード、タッチ操作の各方法でページをめくる。
5. URLが変わらないページ切り替えでも、毎回新しい本文が読み上げられる。
6. ページめくりの途中の画面やツールバー表示だけで読み上げが繰り返されない。
7. 前後のページで文字の差が小さい場合も切り替えを検知する。必要なら差分しきい値・安定待ちを調整する。
8. 素早く複数ページをめくり、古い生成音声が新しいページに混ざらない。
9. 別タブ・別ウィンドウで別サイトを表示しても、その画面を撮影・読み上げない。
10. サイドバーを閉じると監視・再生・バックエンド生成が停止する。
11. 通信切断・バックエンド再起動後に再接続でき、参照音声も再登録される。
12. 参照音声を削除すると一覧から消え、処理の一時ファイルが残らない。

## 検知が合わないとき

- 本文だけを含むよう範囲を調整する。点滅するカーソル、時刻、アニメーションを除く。
- 本文の一部しか変わらない本では、差分しきい値を下げる。
- ページめくりアニメーションで途中の画面を読んでしまう場合、安定待ちを長くする。
- 空白や黒い画像になる場合は、まずChrome自身でその画面を撮影できるか確認する。保護された画面の回避は実装しない。
- サイドバーの幅やブラウザのズームを変えたら、本文範囲を設定し直す。

検証記録にはChrome/U-NEXTの画面種別、GPU、設定、操作方法、検知できたかだけを記載し、本のスクリーンショット・本文・音声は保存しない。
